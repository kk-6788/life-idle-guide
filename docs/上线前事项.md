# 上线前事项

## 静态网页

`web/` 和 `shared/` 可以放在静态托管服务上浏览活动、筛选、随机挑选与收藏。公开 GitHub 源码不会自动创建一个已上线的网站，也不会运行公开评论接口。国内访问情况需实测。

## 微信小程序

先按云端说明填写自己的 AppID、云环境、私有集合、索引与管理员身份，再验证邀请和闲聊功能。云开发部署和开发者预览不代表小程序已经正式发布。发布前核对账号状态、备案、类目、隐私声明与社区功能的适用资格，以后台实际结果为准。

本版闲聊采用人工审核，未接入自动内容安全接口。真实双账号权限隔离、并发抢同码、人数上限和断网恢复需要在自己的环境验收。

## 本机社区服务

`server/` 只监听 `127.0.0.1`，用于本机测试。它没有正式身份体系，不应直接暴露为公网社区后台。公开社区需另行完善身份、内容审核、防滥用、备份与托管。

## 费用和广告

当前代码没有接入广告。云开发价格、免费环境期限与正式发布适用条件需查看自己的后台；发言节流并非费用硬上限。若今后接入广告，应少量、明确标注，不伪装成用户分享，也不要求看广告解锁活动。

## 许可

源码先公开，代码与文字的许可尚未确定。第三方素材权利需分别核对。
