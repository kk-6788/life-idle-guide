# 使用说明

《人生浪费指南》本地原型的使用方法：网页启动、SQLite 审核、静态模式、微信小程序导入与 AppID 限制、内容投稿及费用收录标准。

## 一、启动网页（Windows）

最简单：双击仓库根目录的 `启动网页.cmd`。脚本会检测已有的 Python 3，也可复用已安装的 Hermes Python 环境，找到就用
`server/app.py` 启动本机服务（**只监听 127.0.0.1:8765**），然后提示你在浏览器打开
<http://127.0.0.1:8765/>。脚本**不会自动安装 Python**，也不改机器设置；没有 Python 时只给出提示。

手动启动（等价命令，路径从仓库根目录执行）：

```bash
python server/app.py
```

服务默认使用 `work/community.sqlite3` 数据库，首次启动自动创建。可用参数：

```bash
python server/app.py --port 9000       # 换端口（仍只监听 127.0.0.1）
python server/app.py --db path.db      # 指定数据库文件
```

## 二、SQLite 社区审核

发布/评论进入 `pending`，公开展示前需在本机命令行审核（无匿名管理员 HTTP 接口）：

```bash
# 查看待审核内容与举报（默认只列 pending）
python server/moderate.py list

# 查看全部状态与所有举报
python server/moderate.py list --all

# 批准 / 隐藏某条帖子或评论（类型 post|comment，id 见上一步输出）
python server/moderate.py approve --type post --id 1
python server/moderate.py hide --type comment --id 2
```

举报只被记录（`list --all` 里可见），不会自动封禁，由你本机处理。

## 三、静态模式（不开社区服务）

只想浏览内容、不启动社区：在仓库根目录用 Python 标准库起一个只读静态服务：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8000/web/>。此时"大家闲聊"会明确显示社区尚未开放，
不能发布、不能评论——这是**如实**的显示，不会用假数据冒充线上社区。

## 四、微信小程序

### 4.1 这是可导入的源码

`miniprogram/` 是微信原生小程序。v0.8 包含随机转盘、30 人邀请码入口及云端闲聊。公开源码需要配置自己的云环境才能使用邀请与闲聊。

### 4.2 导入步骤

1. 在微信开发者工具导入 `miniprogram/`。
2. 将占位 AppID `wx0000000000000000` 换为自己的 AppID，并同步修改云函数及测试中的 AppID。
3. 在 `miniprogram/config.js` 填入自己的云环境 ID。需先按 `cloudfunctions/README.md` 完成经用户批准的依赖安装、私有集合/索引、邀请码初始化和云函数部署。
4. 配置管理员后再进行真机联调；云开发部署不等于正式上传、提审或发布。

### 4.3 邀请与闲聊

每枚邀请码激活一个微信账号，总上限 30 人（包括管理员），再次进入不用输入邀请码；分享链接也需邀请资格。留言、回复经人工审核后展示，可以举报和删除自己的内容。新版本不再连接本机 HTTP 社区，不需要填写 API_BASE。

### 4.4 小程序里的隐私

收藏存在手机本地。云端保存用于邀请资格判断的微信身份哈希、自填昵称、留言、回复和举报；试用入口提供说明及同意选项。管理员负责审核、处理举报，用户可以删除自己写的内容。微信后台隐私声明、服务类目仍需按真实功能核对。

### 4.5 同步内容

小程序的 `data/content.js` 与 `utils/guide.js` 由 `tools/sync_content.js` 从唯一内容源
`shared/content.json` 生成。**改内容请改 shared/content.json，然后：**

```bash
node tools/sync_content.js          # 生成/覆盖
node tools/sync_content.js --check  # 只校验一致，不写入
```

不要手抄一份会失真的筛选逻辑或内容；校验不过说明两边不同步。

## 五、内容投稿与费用收录标准

投稿/收录规则见 CONTENT_GUIDE.md，要点：

- 共 40 条内容：34 条零成本 + 6 条有经济成本（cost 为 'paid'）。cost 不是人民币金额，合法值只有 0 和 'paid'；paid 条目必须在 costNote 说明费用构成，不编造具体价格。
- 允许旅游、逛展等付费活动，但不把花钱当作参与的必要条件，不渲染"花了钱才值得"。
- 不收录刷短视频、不提供任何盗版资源；不收录任何电子游戏、买游戏、充值类推荐（现实中的童年游戏保留）。
- 语气温和、不喊口号、不教做人；核心是允许时间没有产出，不是治疗、效率或自律。
- 没有打卡、排行榜、积分、连续天数、必须开心等要求；写"可以做"而不是"应该做"。
- 内容原创；代码与文字的许可尚未确定。

## 六、当前匿名模式的安全边界（重要）

本机服务**只监听 127.0.0.1**，只在本机可访问；没有公网监听、没有云、没有对外接口。
但这是**匿名模式，不是公网安全方案**：

- 一旦你把这类服务暴露到公网，匿名用户可提交内容，需人工审核，无法追责到个人；
- 没有身份体系、没有速率控制之外的防滥用、没有内容安全过滤（仅做长度/类型校验，恶意标签按纯文本显示）。
- 因此**不要**把本机匿名接口直接当作可公网部署的社区后端。公开上线前请阅读 docs/上线前事项.md。
